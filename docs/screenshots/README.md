# Screenshot Checklist

Capture these from the deployed application using non-sensitive demonstration accounts:

1. Public homepage and Google sign-in.
2. Authenticated navbar and calendar selection with owned/shared calendars.
3. Month and hourly week/day calendar views with multiple event types.
4. Create/edit event form, including recurrence end date.
5. Event RSVP and busy-only display from a second account.
6. Calendar membership management.
7. Friend search, requests, and friend list.
8. Account and protected admin pages.
9. One mobile-width view.

Do not include real personal email addresses or authentication tokens in submitted screenshots.
